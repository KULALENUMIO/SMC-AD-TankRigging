# SMC-AD+ Unity タンクリギングプラグイン（v0.7.0-alpha）

> [!WARNING]
> **α版・試作品です。** [SMC-AD](https://github.com/KULALENUMIO/SMC-AD) と組み合わせて使うことだけを前提にしています。
> 使い方・データの形式は予告なく変わります。導入前の注意はリポジトリの [README](https://github.com/KULALENUMIO/SMC-AD-PLUS-UNITY-TANK-RIGGING#導入するときの注意) を読んでください。

SMC-AD で取り込んだ戦車モデルに、同梱の履帯（転輪一式 + リンク 1 枚）を組み合わせ、
**WASD とマウスで操縦できる戦車**にする Unity エディタ拡張です。
車体だけを簡素な物理演算（Rigidbody）で動かし、履帯は物理演算せずに描画だけで地形に沿わせるので、軽く動きます。

- 動作環境: Unity 6.3（6000.3 以降）、**HDRP 17.3 以降**（0.8.0 から HDRP 専用。URP 版は `urp-final` タグ）、Input System（パッケージの依存として自動で入ります）
- 導入（どちらか）
  - Git から: Package Manager > + > **Add package from git URL…** に
    `https://github.com/KULALENUMIO/SMC-AD-PLUS-UNITY-TANK-RIGGING.git?path=/com.tankrig.unity`
  - ローカルから: Package Manager > + > **Add package from disk…** > このフォルダの `package.json`
- ライセンス: MIT（[LICENSE.md](LICENSE.md)）
- 転輪・履帯のモデル（FBX）はパッケージに同梱されていて（`Tracks~`）、組み立てを始めると `Assets/TankRig/Tracks` に自動でコピーされます。

## 使い方

`Tools > Tank Rig > 戦車組み立てウィンドウ` を開きます。最初に戦車モデルと部位を指定して「組み立てを始める」を押すと、
手順ごとのタブ（① 部位 〜 ⑥ 走行・主砲）に分かれた画面になります。① から順に進め、最後にいちばん下の **「戦車を完成させる」** を押します（どのタブからでも押せます）。
いくつかの中から選ぶもの（転輪の数、履帯のデザイン、ポイント、機銃・副砲塔、走行方式、機銃のひな形）はプルダウンにまとめ、細かい設定は ▶ で開く欄にしまってあります。
シーンビューでポイントや機銃のハンドルをクリックすると、そのタブが開きます。

**視点・スナップ**（タブの上。どのタブでも使えます）
- **視点: 正面 / 側面 / 上面** … シーンビューを正投影にして向きを固定する三面図モード。四角いハンドルをドラッグすると、その面の中だけで動きます（奥行きは変わりません）。回転ツール（E）ではその面の中で向きを回せます。ブロックのグリッド（濃い線は 4 ブロック = 1 m ごと）が出ます。「自由」（または選んでいるボタンをもう一度）で元の視点に戻ります。
- **スナップ: 1 ブロック / 1/2 / 1/4** … 履帯・ポイント・機銃・砲口の位置を Scrap Mechanic のブロック（0.25 m）のグリッドに合わせます。グリッドはモデルの軸に沿っていて、原点はモデルのブロックの角から自動で求めます。

**はじめに: 戦車モデルと部位** — シーンに置いた戦車を指定すると、車体・砲塔・砲座・砲身を自動検出します（SMC-AD の SMBody / SMJoint から。なければ階層から推定）。
- **砲座（必須）**: 主砲の上下（俯仰）で回る部分。
- **砲身（なくても可）**: 発砲時に前後に後退する部分（砲座の子、または砲座と一緒に動く別オブジェクト）。指定しないと発砲時の後退は起きません。
「組み立てを始める」で `Tank_<名前>` というルートが作られ、各ポイントが仮配置されます。前方向は主砲の向きから決まります。

1. **① 部位** — 部位と回転軸の確認、砲身のあとからの指定・解除、ブロックの大きさ、「前後を反転」、「別の戦車を組み立てる」。
2. **② 履帯** — **転輪**（6 輪 / 7 輪）と**履帯のデザイン**（標準・平板・V字・ゴムパッド・スケルトン）をプルダウンで選び、「履帯を配置する（自動フィット）」。
   デザインはどれもピッチ 0.25 / 幅 0.5 / ピンと接地面の位置が同じなので、配置後でもいつでも切り替えられます（`TankTrack_Link_*.fbx` を同じ規格で作って取り込めば、選択肢が増えます）。
   同梱の転輪・履帯 FBX は最初に自動で `Assets/TankRig/Tracks` にコピーされます。「FBX の指定・取り込み」を開くと、FBX の直接指定、「同梱の履帯を取り込む」（コピーし直し）、「フォルダから…」（自作の FBX）があります。
   シーンビューで**左の履帯**をドラッグすると、右は自動で左右対称になります。スライダー（左右の間隔・高さ・前後・大きさ・**厚さ**）でも調整できます。厚さは車軸方向だけの倍率です。
   「ブロック単位で動かす」を開くと、外へ・内へ・上へ・下へ・前へ・後ろへのボタンでスナップの細かさずつ動かせます（位置はブロック数で表示）。「リンクの詳細」ではピッチとピンの位置を変えられます。
3. **③ サスペンション（トーションバー）** — いまの転輪の位置が「地面での静止位置」。転輪ごとに後ろ側に支点のあるアームがあり、
   荷重がないと「伸び」の分だけ下がりながら後ろへ弧を描き、押されると「縮み」の分だけ上がります。
   履帯は全部の転輪が伸び切ったときにちょうど張る長さなので、静止時は上側が少したわみ（上部転輪の間ごと）、伸び切るとピンと張ります。
   プレビューのスライダーで縮み〜伸びを確認でき、シーンビューにアームの支点と弧が表示されます。「車体の揺れ」は加減速・旋回での傾きの強さです。
4. **④ ポイント** — 主砲の砲口・エンジン排気・前照灯・後部灯をプルダウンで選び（✔ = 配置済み）、「クリックで配置」→ シーンビューで戦車の表面をクリック。
   置いた後は矢印で移動、回転ツール（E）で向きを変更。排気・前照灯・後部灯は「左右対称」で反対側にも自動で置かれます。「すべて自動で仮配置し直す」もあります。
5. **⑤ 武装** — 「機銃」と「副砲塔」の切り替え。どちらも、上のプルダウンで編集するものを選び、「+ 追加」「削除」で増減します。
   - **機銃**: 「+ 追加」から同軸機銃 / 砲塔機銃 / 車体機銃を選んで、いくつでも追加できます（同軸 = 砲座と一緒に上下、砲塔 = 砲塔と一緒に旋回、車体 = 車体に固定）。
     名前、取り付け、発射ボタン（左クリック / Space / 中クリック・F）、照準に向く範囲（車体機銃のボールマウントなど。0 で固定）、位置、
     性能（発射レート、弾の広がり、射程、曳光弾の頻度と速さ、ベルトの弾数と交換時間、着弾エフェクトの量）を設定できます。性能は「ひな形」から軽機関銃・重機関銃・弾数無限を選んでまとめて設定することもできます。
   - **副砲塔**: 砲塔（旋回）・砲架（上下）・砲身（後退）をシーンからドラッグして指定します。**どれも空のままで構いません**。
     ないものは動かないだけで、残りは正しく動きます（砲塔だけ → 左右だけ照準、砲架だけ → 上下だけ、砲身だけ → 固定で後退あり、全部なし → 砲口の向きに撃つ固定砲）。
     武器は砲か機銃。旋回範囲（全周 / 左右の角度）、俯仰角、速度、装填時間・火力（砲）または機銃の性能を設定します。砲口は砲身・砲架の先端に自動で置かれ、「クリックで配置」「自動」で置き直せます。
     主砲の部位やほかの副砲塔と同じオブジェクト、車体などを指定するとウィンドウに警告（⚠）が出て、完成時にはその部位だけ外します。
6. **⑥ 走行・主砲** — **走行方式**（物理演算 / 物理なし）と車重、最高速度、後退速度、**加速・ブレーキ・操作の反応**、旋回速度、砲塔の旋回速度、俯仰角、装填時間、**主砲火力**。
   主砲火力（1 = 標準）を上げるほど、車体への反動・のけぞり、砲身の後退量（上限 0.8 m。砲身を指定したときのみ）、カメラの揺れ、発砲炎と煙の大きさが比例して大きくなります。
   W / S を離すとブレーキの強さ（実際は履帯の摩擦が上限）ですぐ止まり、A / D を離すと旋回もすぐ止まります。

**戦車を完成させる**（いちばん下） — 操縦・照準・武装・エフェクト・ライト・三人称カメラ・物理（Rigidbody と当たり判定）を組み込みます。設定を変えたら押し直してください。「▶ 試す」でそのままプレイできます。
「完成時のオプション」を開くと、テスト用の地面（坂・丘・的・壁・石・丸太・段差 50 / 80 cm・波状路）を作るか、メインカメラを三人称カメラにするかを選べます。

## 操作（プレイ中）

| 操作 | 内容 |
|---|---|
| W / S | 前進・後退 |
| A / D | 旋回（止まっていれば超信地旋回） |
| マウス | カメラ（砲塔と主砲が画面中央の照準点に向かって旋回） |
| 左クリック | 主砲（発砲炎・煙・光・反動・着弾の土煙） |
| Space | 機銃（曳光弾） |
| 中クリック / F | 副武装（副砲塔など、発射ボタンを「副武装」にした武器） |
| 右クリック | ズーム |
| ホイール | カメラ距離 |
| L | ライト |
| Esc | カーソル解放（クリックで戻る） |

画面中央の十字が照準、四角が主砲の実際の向き（緑 = 装填完了）、小さな十字が副砲塔の向きです。左下に装填・弾数が出ます。

### 照準器（V で切り替え）

三人称 → 直接照準器（光学）→ デジタル射撃画面（ディスプレイ）→ 全周ゴーグル（VR）→ 三人称 の順に切り替わります。照準器の中では次のキーも使えます。

| キー | 働き |
|---|---|
| ホイール | 倍率・視野 |
| R | レーザー測距 |
| 1〜4 | 弾種 |
| N | 照明（光学） |
| T | サーマル / 昼間（ディスプレイ） |
| B | 白黒反転（ディスプレイ） |
| G | 目標の指定・解除（ゴーグル） |

倍率・視野・解像度・縦横比・目盛り・色などの数値は、すべてプロファイル（Assets > Create > Tank Rig > 照準器）で変えられます。詳しい説明と、既定値の根拠にした資料は [Documentation~/Sights.md](Documentation~/Sights.md) にあります。

## 仕組み

- `TankController`（物理モード）… **車体だけ**を Rigidbody で動かします。
  - 転輪 1 輪につき縦のレイ 5 × 3 本（転輪の前後 5 か所 × 履帯の幅方向 3 か所。円が地面にめり込まない高さを求める）。段差の角には転輪が転がりながら乗り上げ、履帯の端にかかった石でも持ち上がります（`widthSamples` で幅方向の本数を変更可）。
    トーションバーはバネ + ダンパーで、モデルの転輪位置がちょうど静止車高になる硬さ（車重 ÷ 転輪数 ÷ 伸び）。縮み（標準 28 cm）を超える障害物は、その角の車体を上限つきの速さで持ち上げて乗り越えます。
    転輪が押し上げられる速さ・ダンパーの速度・1 輪の力に上限があり、障害物の角で車体が跳ね上がらないようにしています。
  - 左右の履帯の駆動力は、その側の接地している転輪に荷重の割合で分け、各転輪の接地面の傾きに沿って押します（段差の角に乗った転輪は角に沿って、平らな所の転輪は平らに）。前後（速度）と旋回（左右差）は別の制御で、旋回は速く反応します。
    坂や横斜面では重力の分をあらかじめ打ち消すので、止まった戦車がずり落ちたり、斜面を横に滑ったりしません。エンジン出力（標準 25 kW/t）の上限があり、急な坂や高速域では牽引力が頭打ちになります。
    力の配分は旋回が先（片側の余力の 7 割まで）、残りを前後に使うので、加速中でも曲がれます。
    上限 = 摩擦 × 接地荷重（加速側はエンジンの牽引力、ブレーキ側はブレーキの強さも）。横滑りは摩擦で止めます（重心の真横にかけるので旋回は妨げません）。重心は履帯の中央の上に置きます。
    加減速・旋回・着地・発砲の反動での車体の揺れは、力のかかる位置から自然に出ます。
    旋回中は横方向の加速度に比例して車体が外側へ傾きます（「サスペンション」の `rollPerLateral` 度 / (m/s²)、上限 `maxTurnLean`。`bodySway` を 0 にすると傾けません）。
  - 前後の起動輪・誘導輪は、同じ 5 本のレイで障害物を見て、めり込んだ分だけ柔らかく押し返し（硬い当たり判定は使わない）、進む向きの段差・丸太にはベルトが食いついて車体を引き上げます。80 cm 程度の段差も止まった状態から登ります。
  - 当たり判定は簡素：車体（メッシュを高さ 4 段に切った凸形状）、砲塔の箱、履帯側面のカプセル。静止時は地面から浮いていて、転輪のバネが車体を支えます。
  - 接地中と離れた直後は、上向きの速度と縦・横に傾く速さに上限をかけます（めり込みの押し戻しも 2 m/s まで）。
- `TankController`（Kinematic モード）… 物理なし。4 点の接地レイで高さと傾きを決める軽い走行（AI の大量配置向け）。
- `TankTrack` … **描画だけ**。転輪の円を包む経路（凸包）にリンクを並べ、速度に合わせて送り、転輪を回します。
  転輪の位置は物理のレイの結果を、車体と同じ補間（直前 2 ステップの間）で描くので、車体と転輪と地面がずれません。下側の履帯はリンク 1 枚ごとに履帯の幅方向 3 か所の短いレイで地面を調べ、石や段差の上に持ち上げます（カメラから 80 m より遠い戦車では省略して負荷を軽減）。
  履帯の長さは一定で、余った分は上側のスパンのたわみになります。リンクは保存されず、毎回生成されます（エディタでもプレビュー）。
- `TankCamera` … War Thunder 風の三人称カメラと HUD。自分の当たり判定は無視します。
- 別のエフェクトを付けるためのフック: `TankController.GunFired`（主砲・副砲の発砲。砲口・火力・当たった位置）、`RoundFired`（機銃 1 発ごと。向き・性能・曳光弾か・当たった位置）、`CurrentInput`（今の入力）。`builtInEffects` をオフにすると組み込みのエフェクト（発砲炎・煙・光・曳光弾・着弾・排気煙）を止めます。
- `TankFx`（リアルなエフェクト）… 機銃・副砲の発砲（口径で大きさ）、排気、土煙と土塊、履帯の巻き込み、主砲の発砲を、組み込みのパーティクルの代わりに出します。
  ビルダーの「リアルなエフェクト」（既定オン）で付き、既存の戦車には Tools > Tank Rig > リアルなエフェクトを付ける。`gunFlashes` / `exhaust` / `dust` / `trackSpill` で個別にオン / オフ、細かい数値は `TankExhaustFX` / `TankDustFX` / `TankTrackSpillFX` と、撃った砲口に付く `GunFlashFX` にあります。
  粒子は CPU で動かし、HDRP のカスタムパス 1 つ（`GunFlashPass`、シーンの「Tank Rig FX Pass」）で描きます。何にも当たりません。
  煙と土煙は地面・戦車・互いに影を落とし（`particleShadows`）、排気と炎の後ろは陽炎で揺れます（`heatHaze`）。
  主砲（`mainGunBlast`、口径 `mainGunCaliberMm`）: 既定はシミュレーションから焼いたフリップブックの軽いパーティクル（`MainGunFX`: 炎・火球・砲口の煙・土煙・衝撃の土煙・小石。負荷はほぼゼロ）。
  重いもの（プレイ中に作る）: `mainGunSimulation`（撮影用: 主砲の爆風を GPU で計算、小石 `gravel`、品質 `blastQuality` 0〜2、既定 2 = 低。プレイ中は `SetMainGunSimulation(true)`）、`ruts`（地面が実際にへこむ轍。地面は 1〜2 m 程度に細かいメッシュの HDRP/Lit か Unity Terrain）。
  撮影用には `mainGunSimulation` + `blastQuality` 0（高）と `dustAmount` 1 がおすすめ。轍の地面シェーダーはプロジェクトの HDRP から自動で作られます（Tools > Tank Rig > 轍の地面シェーダーを作る）。
- `useExternalInput` + `externalInput` で AI やネットワークからも操縦できます（`holdMain` = 左ボタン押しっぱなし、`fireSecondary` = 副武装）。`Teleport()` でリスポーン。

## 前提・制限

- 履帯 FBX は「長さ方向 = X、車軸 = Z、外側 = 側板の反対側」の向きを前提にしています（転輪一式は名前に `RoadWheel` / `ReturnRoller` / `EndWheel` を含む子オブジェクトを転輪として扱います）。
- 自作のリンクは同梱品と同じ規格にしてください: ピッチ 0.25 m、幅 0.5 m、原点 = リンクの中心（ピン軸の高さ）、ピンは前後 ±0.125 m、上（+Y）が転輪側、接地面は原点の 0.094 m 下。
- 同梱モデルの元データは、リポジトリの `Blender/TankTrack_Models.blend`（Blender 5.3）です。
- 弾道（今は直線のレイ）、被弾・ダメージはまだありません。
- アームそのもののメッシュはありません（動きだけ）。
- 履帯の周長はピッチで割り切れるよう、リンクの間隔をわずかに伸縮させています。
