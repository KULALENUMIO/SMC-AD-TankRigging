# Changelog

## [0.8.0-alpha] - 2026-11-21
### Changed
- **HDRP 専用になりました**（Unity 6000.3 / HDRP 17.3）。URP 版は `urp-final` タグに残します。
- エフェクトのパーティクルは、パッケージ内の Shader Graph「TankRig/Particle Unlit」（HDRP Unlit、半透明 / 加算）を使います。古いバージョンで作ったエフェクト用マテリアルは、そのまま差し替わります。
- ライトは物理単位（ルーメン）: 発砲光 800,000 lm、前照灯 3,000 lm、尾灯 60 lm（ブレーキで 3 倍）。地面は HDRP/Lit。

## [0.7.0-alpha] - 2026-11-14
### Added
- 機銃をいくつでも追加（同軸・砲塔・車体）。名前、発射ボタン、照準に向く範囲（ボールマウント）を個別に設定。
- 機銃の性能を調整: 発射レート、弾の広がり、射程、曳光弾の頻度と速さ、ベルトの弾数と交換時間、着弾エフェクトの量（ひな形: 軽機関銃・重機関銃・弾数無限）。
- 副砲塔をいくつでも追加。砲塔（旋回）・砲架（上下）・砲身（後退）はどれも任意で、ないものは動かないだけ。武器は砲か機銃、旋回範囲・俯仰角・速度・装填時間・火力を個別に設定。主砲やほかの副砲塔と部位が重なるなど使えない部位は、ウィンドウで警告し、完成時に外して動かす。
- 副武装の発射ボタン（中クリック / F）。HUD に副砲塔の照準マーカーと装填・弾数を表示。
- 三面図モード（正面・側面・上面）: シーンビューを正投影で固定し、その面の中だけで履帯・ポイント・機銃・砲口を動かす。ブロックのグリッドを表示。
- Scrap Mechanic のブロック単位のスナップ（1 / 1/2 / 1/4 ブロック）。グリッドの原点はモデルのブロックの角から自動で求める。履帯はボタンでブロック単位に移動できる。
- 旋回時の車体の傾き（Physics モード）: 横方向の加速度に比例して外側へ傾く（`rollPerLateral` 度 / (m/s²)、上限 `maxTurnLean`、`bodySway` で強さ）。これまでは 1° 程度しか傾かなかった。
- エフェクト用のフック: `TankController.GunFired` / `RoundFired` イベント、`CurrentInput`、組み込みエフェクトを止める `builtInEffects`。
### Changed
- 組み立てウィンドウを整理: 手順ごとのタブ（① 部位〜⑥ 走行・主砲）に分け、「戦車を完成させる」は常にいちばん下に表示。転輪の数・履帯のデザイン・ポイント・機銃 / 副砲塔・走行方式・機銃のひな形はプルダウンにまとめ、FBX の取り込み・ブロック単位の移動・リンクの詳細・機銃の性能・完成時のオプションは開閉式の欄に。視点とスナップは 1 行に。機能はそのまま。
- 機銃はポイントから武装のタブに移動。v0.6 までの機銃は、ウィンドウで開くと自動で一覧に移る（完成済みの戦車は「戦車を完成させる」を押し直すまで旧形式のまま動く）。

## [0.6.0-alpha] - 2026-11-14 (最初の公開・α版)
### Added
- 履帯のデザインを 5 種類から選択（標準・平板・V字・ゴムパッド・スケルトン）。配置後でも切り替え可能。
- 転輪・履帯の FBX をパッケージに同梱（`Tracks~`）。組み立て開始時に自動でプロジェクトへコピー。
### Changed
- 転輪（転輪・上部転輪・起動輪・誘導輪）と側板のメッシュを作り直し、面の欠けを解消。
- 転輪のテクスチャを自作の小さなカラーパレットに置き換え（見た目の色は同じ）。

## [0.5.0] - 2026-11-14
### Changed
- 主砲を「砲座（上下・必須）」と「砲身（後退・任意）」に分割。砲身がなければ発砲時の後退なし。

## [0.4.0] - 2026-11-14
### Changed
- サスペンション・履帯・駆動の地形追従を改良（転輪ごとの 5×3 レイ、補間描画、坂のずり落ち防止、出力上限）。

## [0.3.x] - 2026-11-14
### Added
- 車体のみ Rigidbody の物理走行、トーションバー、主砲火力。
### Fixed
- 障害物での跳ね上がり、低速旋回の効きの悪さ。

## [0.2.0] - 2026-11-14
### Added
- 履帯の厚さ、トーションバー式サスペンションと履帯のたわみ。

## [0.1.0] - 2026-11-14
### Added
- 初版: 組み立てウィンドウ、左右対称の履帯配置、エフェクトポイント、WASD + マウス操縦。
