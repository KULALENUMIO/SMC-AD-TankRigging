# Changelog

## [0.9.0-alpha] - 2026-11-24
### Changed
- **名前を整理**: パッケージ ID `com.tankrig.unity` → `com.smcad.tankrig`、表示名「SMC-AD+ Unity Tank Rigging Plugin」→「SMC-AD Tank Rigging for Unity」、リポジトリ SMC-AD-PLUS-UNITY-TANK-RIGGING → SMC-AD-TankRigging。古いパッケージを外してから入れる（コードの名前空間・アセンブリ名 `TankRig.*` はそのまま）
### Added
- **ターレットリング内装**（`TurretRingInterior`、Tools > Tank Rig > ターレットリング内装を付ける。普段は非表示、`Show(車体側, 砲塔側)` で表示）: 中身のないモデルでも、リングの所に車内が見える疑似内装。車体側 = 屋根の円盤に、リングの軌道輪・内歯車・車内（床のトーションバー、スリップリング、機器、消火器、運転席への通路）。砲塔側 = 砲塔の底の円盤＋バスケット形の代理メッシュに、リング・吊り下げバスケット（柱・手すり・穴あき床・座席）・見上げた砲塔の中（砲尾・機器）。シェーダー `TankRig/Turret Ring Interior`（手続きの形をレイマーチ、西側の配置）。内径（既定 2.25 m）に合わせて内装ごと伸び縮みし、リングの幅は別に調整できる。照明は内装専用の固定で、外の光や影には影響されない。
- **照準カメラを砲に固定**（`TankSight.fixedToGun`、既定オン、光学・ディスプレイ）: 照準カメラの位置と向きは砲座に固定され、砲と一緒にしか動かない（後座では動かない）。視界の中心 = 砲の向き。マウスで砲を直接動かし、命令は砲の少し先（視野の 5%）までしか進まないので、マウスを止めればすぐ止まる。照準の範囲は砲の俯仰角の範囲。発砲の揺れは上へ一度跳ねて戻るだけ。自車を視界から隠す（`hideOwnTank`）。以前の照準線を独立に動かす方式は `fixedToGun` オフで使える。
- **主砲の煙を真上から見ても自然に**: 焼いた火球・砲口の煙・土煙は真横から見た絵なので、見下ろすと地面に立つ板（底辺が一直線）に見えていた。同じシミュレーションを真上からも焼いた 3 枚（`FlashAtlas.top`）を加え、見下ろす角度（約 21〜46°）で横の絵から地面と平行なカードへ切り替える（見えていない方は描かない）。横の絵の地面側の縁も見下ろすほど薄くする。焼く時、シミュレーションの箱の端で煙が直線に切れないよう、箱の端の数セルで薄める。アトラスは 6 枚、約 48 MB。
- **C: 見回す**（押している間）: 砲塔と主砲をその場で止め、カメラだけを回す。離すとカメラが主砲の向きに戻る（砲塔は振れない）。`TankCamera.freeLookToggle` で押すたびの切り替えに。`TankController.holdTurret`。
- **Shift: 照準**: 照準カメラに入る / 三人称に戻る。カメラは**ディスプレイ式**（射撃画面）か**直接照準式**（光学照準器）を選べる（`TankSightRig.aimSight`、`aimHold` で押している間だけに）。V は従来どおりすべての照準器を順に切り替え。
- **照準カメラのポイント**（組み立てウィンドウ ④ ポイント「照準カメラ」、`TankRigSetup.sightPoint` / `sightKind`）: 砲座の子（砲と一緒に旋回・俯仰、後座では動かない）、自動の仮配置は砲の付け根の横・上・少し前。「戦車を完成させる」で光学・ディスプレイ両方の照準器の視点（`eyePoint`）になり、Shift の照準カメラの種類が設定される。
- 照準器 3 種類（V で三人称と切り替え）。数値はすべてプロファイル（ScriptableObject）で変えられる。
  - 直接照準器（光学）: 倍率と実視界、接眼レンズの円、西側（十字 + ミル目盛り）とソ連・ロシア（山形・見越し目盛り・測距曲線・弾種ごとの距離尺）のレティクル、照明、安定化 / 砲と連動。
  - デジタル射撃画面: 解像度・フレームレートを持つセンサーカメラ、任意の縦横比のモニター、光学視野と電子ズーム、疑似サーマル（白黒反転・ゲイン・レベル・ノイズ）と昼間カメラ、射撃統制の記号。
  - 全周ゴーグル（VR）: 首振り（VR ヘッドセット / マウス）、車体の透過、方位テープ・水平線・主砲の線・車体の外形・目標マーカー・ミニマップ、目標指定で主砲が追従。
- レーザー測距（最短・最大・刻み・最初 / 最後の反射）と弾種の選択（1〜4）。
- 記号は HDRP のカスタムパス（After Post Process）で描くので、露出やポストエフェクトに影響されない。
- `TankController.aimSource`（照準の差し替え口）、`TankCamera.LookAlong`。
- **リアルなエフェクト**（`TankFx`、ビルダーの「リアルなエフェクト」で既定オン。既存の戦車には Tools > Tank Rig > リアルなエフェクトを付ける）。組み込みのパーティクルを部分ごとに置き換える（主砲は従来のまま）:
  - 機銃・副砲の発砲: 発砲炎（芯・円錐）、フラッシュハイダー / マズルブレーキの噴流、中間フラッシュ、二次燃焼の火球、わずかな煙、火花、一瞬の光。大きさは口径から決まる（`MachineGunSpec.caliberMm` 既定 7.62 mm、`TankSecondaryTurret.caliberMm` 既定 30 mm。ビルダーで変更可）。
  - 排気: スロットルに応じた量と速さ。開けた瞬間の黒煙、風に流れてすぐ消える。
  - 土煙と土塊: 左右の履帯の対地速度（旋回で外側が多い）から、地面の色（地形のレイヤー / メッシュの色）で。
  - 履帯の巻き込み: 実際のベルトの形に沿って土が上を回り、上側からこぼれ、前で振り落とされる。
  - どれも何にも当たらず、1 つの HDRP カスタムパス（`GunFlashPass`、シーンになければ追加）で描く。負荷は CPU 0.5 ms 前後。
  - **主砲の発砲（重い、プレイ中に作る）**: GPU で計算する爆風（前駆ガス・火球・砲口の煙・衝撃波・地面と車体から舞う砂塵）と、戦車の周りに飛ぶ小石。煙が残るうちに次を撃てる（`blastSlots`、既定 2）。品質 `blastQuality` 0 高 / 1 中 / **2 低（既定）**。1 フレームの計算に上限があり、重いフレームが続いても悪化しない（遅いときは煙が少しゆっくりになる）。
  - **履帯の轍（重い、プレイ中に作る）**: 地面が実際にへこむ（深さ・グローサー・土手・湿った底、影も落ちる）。履帯の幅・長さ・位置はリンクから自動で測る。地面は細かいメッシュの HDRP/Lit か Unity Terrain。
    轍の地面シェーダー（`TankRig/GroundRuts` / `TankRig/TerrainRuts`）は HDRP のシェーダーの改造なので、パッケージには入れず、プロジェクトの HDRP から `Assets/TankRig/Generated/Resources/TankRigRuts` に自動で作る（HDRP を更新すると作り直す。手動: Tools > Tank Rig > 轍の地面シェーダーを作る）。
  - 負荷の目安（RTX 3080、1080p、プレイヤー、毎フレーム GPU 待ちの厳しめの計測）: 軽いもの +1〜4 ms（土煙の量 `dustAmount` 既定 0.5 で軽く）、轍 ほぼ 0、主砲 1 発 低 +3〜5 / 中 +5〜7 / 高 +8〜12 ms。
- 粒子の描画（`GunFlashPass`）を強化:
  - **半解像度描画**（既定オン）: 煙・土煙・排気などの柔らかい粒子は半分の解像度に描き、半解像度の深度（2×2 の最も近い / 遠い深度をチェッカー状に保持）を手がかりに 4 点で戻す（深度差 2% 以内の画素だけ使うので戦車の輪郭ににじまない）。閃光・炎・火花・土粒など鋭いものはフル解像度。土煙 1.5 → 0.6 ms、排気 0.8 → 0.1 ms（1080p、RTX 3080）。
  - **スプライト粒子**（`PType.Sprite`）: フリップブック（テクスチャ配列、`FlashAtlas`）、コマ補間、ランダム反転・回転、侵食（薄い所から消える）、地面とのソフトフェード、カメラ近接フェード、温度による発光。
  - 照明 4 方式: 一様 / 球の擬似法線 / ノーマルマップ / **scatter**（不透明度を光学的厚さとして扱い、太陽方向の前方散乱、2 段階の自己影、逆光の縁、厚い所の環境光の暗さ）。検証用に計算で作るフリップブック（煙・火球）を内蔵。
- **主砲の煙のフリップブック**（`Resources/TankRigFX/BlastAtlas`、`FlashAtlas.Default`）: 主砲の GPU シミュレーション自体を、戦車なし・無風・映画品質で撃ち、真横から正射影で 4×4 コマ（256 px）に焼いたもの。火球（0〜0.25 秒）・砲口の煙（0.15〜3 秒）・地面の土煙（0.06〜2.9 秒）の 3 枚。被覆率 1−e^−kτ・温度・明るさ（BC7）と法線（BC5）、約 17 MB。カードは焼いた箱の縦横比で描く。
  焼き直し: Tools > Tank Rig > 主砲の煙をフリップブックに焼く（`TankRig.Editor.FlashAtlasBaker.Bake`）。
- **主砲の発砲を軽量なパーティクルに（`MainGunFX`、既定）**: War Thunder の 120 mm の発砲の時間経過に合わせて部品を組み合わせる。炎の円錐・コア・マズルブレーキの噴流・火花（0〜80 ms）、発砲光（〜0.15 秒）、焼いた火球と小さな塊 2 つ（〜0.25 秒）、地面を低く走る衝撃の土煙（0.06〜0.5 秒）、焼いた土煙（地面の色、戦車が隠れない薄さ）と左右の 2 つ、焼いた砲口の煙（風に流れる）、砲口からの白い煙、小石。焼いたカードは砲身の向きに合わせて左右反転し（上下は反転しない）、火球は砲身方向から見ると幅が縮む。
  1 発の負荷は測定誤差内（GPU シミュレーションは低品質でも +4〜5 ms）。最初の 1 発で引っかからないよう、見えない 1 発で準備する。
  GPU シミュレーションは撮影用に残す: `TankFx.mainGunSimulation`（既定オフ）、`TankFx.SetMainGunSimulation(bool)`（プレイ中に切り替え）。主砲の口径 `TankFx.mainGunCaliberMm`（既定 120 mm）。
- **煙のフリップブックを滑らかに**: コマ数 16 → 64（8×8、1 コマ 256 px、アトラス 2048²）。さらにシミュレーションの速度から「次のコマまでの動き」を焼いた動きテクスチャ（`FlashAtlas.C`、BC5、半分の大きさ）を持ち、混ぜる 2 コマをその動きに沿ってずらす（フローマップ方式。`GunFlashPass.flowBlending` でオン / オフ）。コマの切り替わりでガクガクしていた広がり方が連続になった。法線（B）も半分の大きさに。アセットはバイナリ保存（`[PreferBinarySerialization]`）で約 25 MB。
- **発砲後に砲身から噴き出す煙**（`MainGunFX`）: 火球が消えたあと約 4 秒、砲口から細く勢いのある煙の噴流（最初 18 m/s、ガス圧とともに弱まる。小さな粒を毎秒最大 220 個）が真っすぐ伸び、空気で減速して少し昇り、風に流れる（毎フレーム砲口の位置から出るので砲塔が回っても付いていく）。`boreSmokeTime` / `boreSmokeRate` / `boreSmokeSize` / `boreSmokeSpeed` / `boreSmokeOpacity`、チャンネル `wisp`。従来の小さな白いパフ 3 つの代わり。
- **車体から浮き上がる土煙**（`MainGunFX`、チャンネル `hullDust`）: 発砲のたびに戦車のメッシュ（砲 `gunRoot` を除く）を真上から GPU で小さな高さマップ（10 cm）に描いて非同期で読み戻し（Read/Write の無いメッシュでも正確、砲塔の旋回もそのまま）、上を向いた本当の上面（車体上面・砲塔上面・フェンダー）から、爆風が届いた順に（距離 / 340 m/s）薄い土煙を舞い上げる。戦車が埋もれない薄さ（`hullDustPuffs` 70、`hullDustOpacity` 0.4）。上と砲口から離れる向きへ流れ、ほこりの多い所と少ない所がある。1 発で車体のほこりを使い切り、止まっていれば約 30 秒、走ると速く戻る（`hullDustRecover`）。GPU が使えないときは部品の箱の上向きの面で代用（`gpuSurface`）。
- **車体に沿って地面から舞う土煙**（`MainGunFX`、チャンネル `shockDust`）: 砲口の下だけでなく、車体の両脇と後ろの地面からも、爆風が届いた順に土煙が立ち、車体から外向き・車体に沿って後ろへ流れる（車体の幅と長さはサンプリングした表面から毎発測る）。
- **発砲の土煙を実写に合わせて作り直し**（実写の発砲映像と同じ時間軸で比較）: 土煙は丸く柔らかい塊ではなく、ゆがめた多層ノイズによるもこもこした塊（`PType.Dust` の billow モード、`extra.y` = 1）。年齢とともに膨らんで転がり、薄い所から削れて筋になって消える。大きさは最初速く、あとはゆっくり（√t）。下側と襞は暗い。動き: 爆風で 25〜55 m/s の低く強い噴き出し → 空気抵抗で数 m で止まる → 2.5〜4.5 秒漂い、風にそのまま流され、ゆっくり昇る（衝撃の土煙・車体脇・車体上）。濃さは戦車が透けて見える程度（`dustOpacity` 0.3、`hullDustOpacity` 0.3、塊の数も控えめ）。
- **砲身から出る煙を一本の噴流に**: 新しい粒子 `PType.BoreJet`（速度方向に伸びる柔らかい筋、青白く冷めると灰色）。発砲直後 30 m/s、ガス圧とともに弱まり、重なった筋が途切れない噴流になる（`boreSmokeSpeed` / `boreSmokeStretch`）。
- **空中への発砲**（`MainGunFX`）: 火球と砲口の煙を実際の砲身の向き（仰角込み）に沿って置き、カードを画面上の砲身の傾きに合わせて傾ける（傾けるのは仰角の分だけ。砲身の方向から見るときは傾けず、上げた砲の煙はその方向から見ると丸く縮む。地面に当たって平らになった煙の下端は消す）。空中では煙を少し小さく。砲口の下の地面の土煙（焼いた土煙・衝撃の土煙）は仰角とともに減り、約 45° で出なくなる。車体の土煙と車体脇の土煙は爆風の圧力で弱めに残る。
- **周りの土煙の調整**: 発砲の土煙（衝撃・車体脇・車体上）はすぐ薄れ始めず、寿命の 1/4 ほど濃さを保ってから消える（`PType.Dust` の `extra.x`）。寿命を少し長く（衝撃 0.9〜1.6 秒、車体脇 1.1〜2.2 秒、車体上 1.0〜1.8 秒）、細かい土なので風にそのまま流され（`windK` 1）、ゆっくり昇る。車体脇の土煙は履帯のすぐ脇に集まり、やや薄く。
- 向きのある焼いたカード（火球・砲口の煙・土煙）が、カメラが砲身の線をまたぐときに一瞬で左右反転していた（角度が変わるとガクッと変わる）。砲身の方向から見る前後 ±20° ほどで、反転していない絵と反転した絵をクロスフェードする。
- **粒子の影**（`GunFlashPass.particleShadows`、既定オン）: 煙・土煙・排気・焼いたスプライトを太陽から 256×256 の Fourier opacity map（深さ方向の光学的厚さを 2 次までのフーリエ級数で保持）に描き、粒子どうしの日向側の陰りと、地面・戦車に落ちる影（全画面で日光の分だけ暗くする、`sceneShadow` 既定 0.65）に使う。光る火球はほとんど影を落とさない。負荷 0.2 ms 前後。
- **陽炎**（`GunFlashPass.heatHaze`、既定オン）: 排気口付近・炎・火球の後ろの景色を 1/4 解像度のずらしで揺らす（`hazeStrength`）。熱い粒子がいるときだけ動く。
- **走行の土煙を War Thunder 風に**（`TankDustFX`）: 大きく昇る土煙の雲をやめ、起動輪側から後ろへ飛ぶ**泥の筋**（速度で伸びる不透明な筋、新しい粒子 `PType.Mud`、地面の色を濡れた分だけ暗く。前の誘導輪からも少し）、履帯のすぐ後ろの**小さな暗いパフ**、地面を這う**薄い幕**（不透明度 0.22 → 0.1、寿命 4.5 → 2.6 秒、上昇 0.5 → 0.15 m/s）に。`mudRate` / `mudSize` / `mudStretch` / `mudDark`、`kickRate` / `kickOpacity`、`rise`。
- **排気の水平ジェット**（`TankExhaustFX`）: 負荷がかかると、排気口の向きを水平に寝かせた方向へ濃い白っぽい噴流（約 5 m）。回転が上がっていく間がいちばん濃い。アイドルは従来どおり薄く昇る。煤は控えめ（`sootLoad` 0.35 → 0.12、`sootKick` 0.9 → 0.35）。`jetLevel` / `jetSpeed` / `jetDrag` / `jetOpacity` / `riseIdle` / `riseLoad`。
- `MuzzleDebris`（小石）はシミュレーションなしでも使える（`muzzle` / `ignoreRoot` / `channel` を設定して `Throw()`）。`GunFlashFX.Clear()`、`MuzzleDebris.Clear()`。
- `TankTrack` の読み取り専用 API: `PathPoints` / `PathDistances` / `LinkDepth` / `BeltTravel`（ベルトに沿うエフェクト用）。
- `TankController.externalGunFlashes` / `externalExhaust`: 置き換えるエフェクトが、組み込みの機銃・副砲の発砲炎 / 排気煙だけを止める（実行時のみ）。
### Fixed
- 履帯痕が、履帯が実際に接地している範囲より前後に長く付いていた（リンクの判定が甘く、端で上がりかけたリンクまで含み、さらに前後にも肩の傾斜を付けていた）。接地長は転輪から（最初と最後の転輪の間 + 半リンクずつ）、毎フレーム地面に着いている転輪だけで決める（段差で浮いた転輪や、発進で車体が傾いて浮いた端には付けない）。前後は接地の端で終わり、端の数 cm で押し込まれる。土手も接地している長さの横だけ。Stingray 5.49 → 5.24 m、KS-25A3V 6.45 → 6.17 m。
- 履帯痕: 地面の高さを毎フレーム GC なしで調べ、止まっている戦車は同じ跡を押し直さない。
- 車体の土煙が実際には砲身から出ていた（Read/Write の無いブロック部品では部品の箱の上面で代用していたため、回転したブロックの「上」が横を向き、車体の中に埋もれた箱が多く、最も高い砲身ばかりが選ばれていた）。GPU の高さマップに置き換え、選ぶ点もランダムに（以前は連続した点がかたまっていた）。
- フリップブックの焼き込み: `EditorUtility.CompressTexture` は 2 のべき乗でない大きさを黙って圧縮しない（RGBA32 のまま）ため、配列に入れると壊れた模様になっていた。2 のべき乗に揃え、圧縮できなかったら止める。
- 主砲の砂塵が地面から上がらなかった: 砂塵の移流が「行き先のセルの速度」でたどるため、静止した空気へ入れず、放出した地上 0.6 m の層に閉じ込められていた。空のセルは周りの砂塵の速度（量で重み付け）を使う（`MuzzleBlastParams.dustSpread`、既定オン。オフで従来のシート状）。
- 主砲の車体の砂塵: 速さ・上昇・時間幅の設定がコメントの中に入っていて渡っておらず（時間幅 0）、ほとんど出ていなかった。
- スプライト粒子はシードで回転しない（エミッターの角度だけ。焼いたカードは地面が下のまま立つ）。`extra2.w` = ±(10 + 方位角) で向きのあるカード（+ は方向に沿って見ると幅が縮む）。
- 強い反動のあと、物理走行で「Quaternion To Matrix conversion failed」が出ることがあった（車体の回転を正規化）。

## [0.8.0-alpha] - 2026-11-21
### Changed
- **発砲の土煙をつながった細かいものに**: 土煙（billow）の模様を粒ごとの模様からワールド空間の模様（粒が動いた分だけ一緒に運ぶ）に変え、重なった粒が 1 つの雲として続くようにした。模様は約 2 m の塊・40 cm の襞・15 cm の筋の 3 段で、縁ほど薄い所から削れて細かい筋になる。粒は小さく薄くして数を増やし、均等に並べる: 車体沿いの地面 28 → 64（両脇に交互、前後に等間隔）、砲口まわりの衝撃 14 → 32（角度を等分）、車体・砲塔の上面 45 → 110（`hullDustPuffs`、上面全体を均等に）。
- **発砲の土煙が発射と同時に**: 車体沿いの地面・砲口まわり・車体と砲塔の上面の土煙は、爆風の到達時間を 340 m/s → 900 m/s（砲口近くの爆風は音速より速い）で数え、余分な遅れ（衝撃の土煙 60 ms）とフェードイン（寿命の 3% → 0.8%）を詰めた。

- エフェクトのパーティクルは、パッケージ内の Shader Graph「TankRig/Particle Unlit」（HDRP Unlit、半透明 / 加算）を使います。古いバージョンで作ったエフェクト用マテリアルは、そのまま差し替わります。
- ライトは物理単位（ルーメン）: 発砲光 800,000 lm、前照灯 3,000 lm、尾灯 60 lm（ブレーキで 3 倍）。地面は HDRP/Lit。

## [0.7.0-alpha] - 2026-11-14
### Added
