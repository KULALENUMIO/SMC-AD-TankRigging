# 照準器（Sights）

戦車のカメラに 3 種類の照準器を付けて、**V** で切り替えます（三人称 → 光学 → ディスプレイ → ゴーグル → 三人称）。

| 種類 | コンポーネント | 数値（プロファイル） | 作成メニュー |
|---|---|---|---|
| 直接照準器（光学） | `OpticalSight` | `OpticalSightProfile` | Assets > Create > Tank Rig > 照準器 > 直接照準器（光学） |
| デジタル射撃画面（ディスプレイ） | `DisplaySight` | `DisplaySightProfile` | 同 > デジタル射撃画面（ディスプレイ） |
| 全周デジタル射撃画面（VR ゴーグル） | `HelmetSight` | `HelmetSightProfile` | 同 > 全周デジタル射撃画面（VR ゴーグル） |

切り替えと共通の処理は `TankSightRig` が受け持ちます。カーソル、レーザー測距、弾種、発砲時の揺れ、記号の描画、主砲の照準です。

- **新しく組み立てる戦車**: 「戦車を完成させる」で自動的に付きます。
- **完成済みの戦車**: `Tools > Tank Rig > 照準器を付ける` で付けます。

## 数値の入れ方

1. 上の作成メニューでプロファイルを作ります。
2. 照準器コンポーネントの「数値」欄に入れます。空のときは既定値（下の表）で動きます。
3. プロファイルの「︙」メニューにプリセットがあります。
   - 光学: 西側 3x/10x、ソ連・ロシア 8x 固定、ソ連・ロシア 2.7x〜12x
   - ディスプレイ: サーマル 4:3 / 1024×768、ワイド 16:9 / 1920×1080

角度の数値（目盛りの間隔、十字の長さなど）は、プロファイルの「角度の単位」で書きます。

| 単位 | 1 周 |
|---|---|
| NATO ミル | 6400 |
| ソ連・ロシアの千分 | 6000 |
| ミリラジアン | 約 6283 |
| 度 | 360 |

弾種（名前・記号・初速・1 km あたりの速度低下・距離尺の最大距離）は `TankSightRig.ammo` にあり、1〜4 キーで選びます。

## 操作

| キー | 働き |
|---|---|
| Shift | 照準カメラ（`TankSightRig.aimSight`: ディスプレイ式 / 直接照準式）に入る / 三人称に戻る |
| V | 視点の切り替え |
| マウス | 光学・ディスプレイ（既定の「砲に固定」）: 主砲を直接動かす。視界は砲と一緒に動く。ゴーグル: 頭の向き |
| ホイール | 倍率・視野の切り替え。倍率が 1 段だけの光学照準器では、手動の距離（100 m 刻み） |
| R | レーザー測距 |
| 1〜4 | 弾種 |
| N | レティクルの照明（光学） |
| T | カメラの切り替え（ディスプレイ: サーマル / 昼間） |
| B | 白黒反転（ディスプレイ: ホワイトホット / ブラックホット） |
| G | 視線の先を目標に指定・解除（ゴーグル）。指定中は主砲がその目標に付いたまま |
| Esc | カーソル解放 |

スクリプトからも操作できます。

- `TankSightRig.Switch(i)` / `Lase()`
- `TankSight.LookAt(point)`
- `OpticalSight.ZoomIndex`
- `DisplaySight.SetStep(channel, step)`
- `HelmetSight.Designate(point, follow)` / `ReleaseDesignation()`

## 仕組み

- **記号の描き方**: 記号は 1 枚のメッシュ（線・円・文字）で、HDRP のカスタムパス（After Post Process）で最後に重ねます。露出、ブルーム、被写界深度、モーションブラー、TAA の影響を受けません。
- **光学**: カメラを照準器の位置に置きます。接眼レンズの円の直径にプロファイルの「実視界」が収まるように、カメラの視野を決めます。
  - **砲に固定**（`TankSight.fixedToGun`、既定オン。光学・ディスプレイ共通）: 照準カメラは砲座（俯仰する部分）に固定され、位置も向きも砲と一緒にしか動きません（砲身の後座では動きません）。
    - 視界の中心は常に砲の向きです。
    - マウスは砲を直接動かします。マウスが砲塔の旋回より速くても、命令は砲の少し先（視野の 5%）までしか進まないので、マウスを止めればすぐ止まります（行き過ぎない）。マウスを止めている間、命令は空間に止まったままで、車体が揺れても砲がそこを保ちます。
    - 照準の範囲は砲の俯仰角の範囲そのものです。
    - 視点（`eyePoint`）が砲座の子ならそのまま使います。砲塔などの子なら、最初に使った時の砲座からの位置を覚えて使います（砲身の子でも後座では動きません）。
    - 発砲時の揺れは、上へ一度跳ねて元の位置に戻るだけです（`firingShake` 0 で揺れません）。
    - 自車を視界から隠します（`hideOwnTank`、影は残ります）。砲身や防盾が視界をふさぎません。
  - オフにすると従来の動きです。照準線は「独立安定化」と「砲と連動」から選べます。
    - 独立安定化: 照準線は止まったままで、砲が追いかけます。
    - 砲と連動: 視界は砲の向きそのものです。
- **ディスプレイ**: 別のカメラ（センサー）が、プロファイルの解像度とフレームレートで撮ります。その映像を、任意の縦横比のモニターに映します。
  - 電子ズームは、映像の中央を切り出して拡大します（画素が粗くなります）。
  - サーマルは本物の熱ではなく、**明るさから作った疑似サーマル**です（ゲイン・レベル・極性・ノイズ・縦すじ）。
- **ゴーグル**:
  - **車体の透過**: 自分の戦車を消します（影は残します）。外部カメラが映せる仰角の範囲だけ透けます。
  - **記号の位置**: ゴーグルの視野（既定 40°×30°）の中に出します。
  - **VR ヘッドセットがあるとき**: 頭の向きは XR の CenterEye から読み、記号は両目に同じ方向（無限遠）で重ねます。VR がないときはマウスで首を振ります。

## 制限（今の版）

- **弾道**: 主砲の弾はまだ直進（レイキャスト）です。弾種ごとの落下は、ソ連・ロシア式の距離尺の目盛りに使うだけです。照準の中心は、そのまま着弾点です。見越し（移動目標のリード）も計算していません。
- **サーマル**: 物体の温度は使っていません（明るさからの疑似です）。
- **VR**: 実機では未確認です。画面で、VR と同じ「方向で重ねる」描き方は確認しています（`forceAngularOverlay`）。
  - カメラに TrackedPoseDriver を付けないでください。`HelmetSight` が頭の位置を置きます。

## 既定値と資料

公開資料（Wikipedia、メーカーの資料、公開された軍の規格、防衛系の報道）から集めました。資料のない値は推定で、そう書いています。

| 項目 | 既定値 | 根拠 |
|---|---|---|

| 倍率・実視界（ソ連・ロシア固定） | 8x / 9° | T-72 の TPD-K1（https://man.fas.org/dod-101/sys/land/row/t72tank.htm ） |
| 倍率・実視界（ソ連・ロシア可変） | 2.7x〜12x / 20°〜4.5° | T-90 の 1G46（https://crib-blog.blogspot.com/p/soviet-t01-k0x-sight-family.html ） |
| 角度の単位 | NATO 6400 / ソ連・ロシア 6000 | https://en.wikipedia.org/wiki/Milliradian |
